# 부산 유휴 공유재산 지역수요 기반 활용 분석

2026년 Big Data 활용 대회 · 빅데이터 분석 및 시각화 · 개인 참가 · 2026.09

## 목적
부산의 유휴 공유재산 10,102건과 206개 행정동의 생활인구 특성을 결합해, 활용유형별 행정 검토 우선 후보를 선별했습니다. 사업 대상 확정이나 실제 시설 수요 예측이 아닌 의사결정 지원 분석입니다.

## 데이터 및 방법
- 부산 16개 구·군 공유재산: 주소, 면적, 지목, 기관코드
- 2025.03~12 월별 일평균 생활인구: 주거·직장·방문, 6개 연령대
- 공공서비스 공급 자료: 지역아동센터, 다함께돌봄센터, 경로당, 노인교실 (해석 보조)
- Kakao Local API와 행정동 경계를 이용한 공간 연결
- 생활인구의 규모와 입지계수(LQ)를 백분위화하고 두 백분위의 최소값으로 수요균형도 정의
- 172개 유휴재산 보유·연결 행정동에서 Spearman 관계 진단 및 유형별 Pareto 비지배 분석
- 유형별 후보동의 유효면적·지목 확인·비도로 재산으로 확장한 후 주소 기준 중복 제거
- 지목 '대' 및 면적 75㎡ 이상 조건으로 최종 선별 (75㎡는 유효 면적의 75백분위 경계이며 법적 기준이 아님)

## 한계
생활인구는 실제 정책 수요나 시설 부족을 직접 측정한 값이 아닙니다. 행정동 미매칭 60건과 좌표 미확보 65건, 원자료 제공 방식 차이가 공간분포에 영향을 줄 수 있습니다. 실제 활용 적합성은 법적·물리적·경제적 조건과 주민수요를 추가로 검토해야 합니다.
